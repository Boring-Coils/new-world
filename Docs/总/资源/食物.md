# 食物资源

单位是克（g），实现位于 `Scripts/Human/Human.gd`。

| 年龄阶段 | 每日基础消耗 |
| --- | ---: |
| 儿童 | 800 |
| 成年 | 1900 |
| 老年 | 1500 |

雇佣状态不改变基础消耗。每刻食物下降：

```text
每日消耗 / TICKS_PER_DAY × Buff 消耗倍率 + Buff 每刻直接扣食
```

当前 `TICKS_PER_DAY = 1800`。居民最大储食为 `700`。

取食决策没有“低于 100 就 100% 取食”的随机规则。`HumanAIContext` 根据当前食物、
有效每刻耗食和 Buff 权重计算剩余可支撑刻数；`HumanDecision` 将取水、取食和工作
按分数排序。分数相同时优先级为水、食物、工作。

储食降到 `0` 或以下时，居民尝试添加 `Weakness` Buff。
