# 网格

当前世界由 `WorldGridGlobal.WORLD_CELLS = Vector2i(1000, 1000)` 定义，
共有 `1000 × 1000` 格。一格等于 1 米，边长 `WorldGrid.CELL_SIZE = 10` 像素。

- `cell_to_world()` 返回格子中心的像素坐标。
- `world_to_cell()` 返回像素坐标所在格子，但世界外坐标会被夹到边界格。
- 严格范围判断应先使用 `is_in_bounds()`。
- 建筑左上角、出入口、路径和 AI 目标均使用 `Vector2i` 格子坐标。
- 斜向移动只在两侧都不被阻挡时允许。
