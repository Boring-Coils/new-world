# 虚弱

当前实现是 `Scripts/Buff/Types/Weakness.gd`，尚未实现医院、住宅、药品和传染病。

## 触发

居民的水或食物降到 `0` 或以下时，`Human._consume()` 尝试添加 `Weakness`。

## 持续与恢复

- 首次添加时总持续时间为 `10` 个游戏日。
- 独立恢复计时初始为 `5` 个游戏日。
- 每刻只有在水分和食物都大于 `200` 时，恢复计时才减 1。
- 恢复计时先到 0 时，把持续时间置 0，Buff 正常到期，不判定死亡。
- 总持续时间先到 0 且恢复计时仍未完成时，`on_remove()` 调用 `human.die()`。
- 重复添加不叠层、不刷新持续时间，也不重置恢复计时。

## 效果

- 虚弱期间始终禁止工作。
- 基础水和食物消耗倍率为 `0.5`。
- 周期被虚弱中断时按硬中断取消并回滚工作需求，恢复后从完整周期重新开始。
