# 居民动作状态机

当前居民使用 `godot_state_charts`，状态图位于 `HumanAI/StateChart`。

一级动作状态为：

- `Idle`
- `Traveling`
- `Waiting`
- `Working`
- `LeavingWork`
- `Relocating`

`HumanAI.on_tick()` 每刻推进一次状态图；`HumanMotion.on_tick()` 也由 `HumanAI`
控制，同一刻只允许一个所有者推进移动。

状态脚本继承 `HumanStateBase`。覆盖插件回调 `_ready()` 时必须先调用
`super._ready()`，否则状态图内部引用不会建立。

状态图节点和转换以 `Scenes/Human/Human.tscn` 为准。详细职责见
`Docs/v0.0.1.3(居民ai重构)/HumanAI职责与接口.md`。
