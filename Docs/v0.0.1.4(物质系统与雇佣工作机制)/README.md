## 2. 一句话方案

建筑只管理自己的雇佣目标、雇员名单、班次和可选仓库；居民通过独立的工作行为完成
工作周期；全局物资系统负责物品、库存、物品锁定、产出空间预留和所有者消失后的清算。
建筑不需要知道工人在哪，也不需要维护“正在工作”的工人集合。

```text
建筑
├─ 雇佣关系：目标人数、雇员、资格、班次
├─ 工作类型配置：需求、周期规则、产出
└─ 可选库存：默认 1000 体积

居民
├─ 知道自己属于哪个雇主
├─ 工作行为：准备、锁定周期、完成、上报
└─ HumanMotion：唯一移动实现

全局物资系统
├─ 物品定义与库存
├─ 已有物品锁定
├─ 产出空间预留
└─ 所有者消失后的物资清算
```

## 3. 本版范围

本版包含：

- 可雇佣建筑设置目标人数、补齐、解雇和资格复检。
- 居民知道自己被哪个建筑雇佣，并且同一时间最多只有一个雇主。
- 默认班次、下班等待点和雇佣对居民 AI 的改造。
- 工作周期的准备、锁定、结算和中断回滚。
- 仓库建筑、建筑自带库存、物品体积、锁定和空间预留。
- 废料、金属、塑料、线四种物品。
- 与上述规则直接相关的详情页、调试和验证设计。

本版不包含：

- 木材物品、树实体、伐木站或砍伐进度系统。
- 岗位、职业、技能和工种系统。
- 住宅、回家、睡眠和通勤系统。
- 完整物流调度、运输车辆和多人搬运。
- 存档与状态恢复。

伐木只用于说明“可变周期”和“进度锁定”的扩展方式，不是本版交付内容。

## 4. 已确定的核心规则

### 4.1 雇佣

1. 可雇佣建筑由自身定义目标人数，UI 范围为 `0..max_workers`。
2. 建筑可以定义一个隐藏的运行阈值，默认没有。它不是目标人数的下限。
3. 人数不足时，在同一个游戏刻尽可能补齐到目标人数。
4. 人数超过目标时，随机解雇多余数量。
5. 默认只雇佣成年人。是否雇佣儿童和老年人由建筑决定。
6. 一个居民同一时间最多属于一个雇主。
7. 招聘阶段不检查居民能否走到工作建筑。
8. 建筑每刻复检雇员的雇佣资格。资格永久失效时，移除该雇员、通知居民并立即补招。
9. 眩晕、虚弱等临时不能工作默认不解除雇佣，除非建筑明确配置为解除。
10. 没有岗位或职业概念。
11. 缺人时按稳定顺序选择候选居民。没有建筑自定义规则时，使用居民注册顺序。
12. 已雇佣但暂时走不到雇主的居民保留雇佣关系，回到等待点并按决策周期重试。

### 4.2 班次

1. 默认工作时间为当前游戏日的 `[n / 3, 5n / 6)`，其中
   `n = TickManager.TICKS_PER_DAY`。
2. 当前 `n = 1800` 时，默认工作时间为第 `600..1499` 刻。
3. 工作时间外不能开始新工作周期。
4. 如果工作周期开始时处于班次内，允许跨过下班时刻完成当前周期。
5. 下班或未就业的居民前往 `World.WAIT_PLACE` 附近等待。有住宅后优先回家。

### 4.3 工作周期

1. 工作周期是产生一次工作产出的最小时间单位。
2. 时间、需求、产出和具体行为由工作类型决定，可以是可变时长。
3. 周期开始前，居民先取得工作需求、补充水和食物，并预留产出空间。
4. 周期锁定后，口渴、饥饿、下班和普通决策不能中断工作。
5. 周期完成时，锁定需求转为实际消耗，产出写入已预留的库存空间，
   然后向建筑提交一次工作结果。
6. 强制中断时，不产生实际消耗和产出；工作需求自动归还，不要求居民走回仓库。
7. 居民自己的水和食物消耗不回滚。
8. 强制中断会丢弃本轮进度，下一次必须从零开始新的完整周期。
9. 周期预计时间为当前路线、当前速度和固定工作耗时之和，再加 `10%` 安全余量。
10. 产出超过预留体积时，继续寻找其他未预留仓库空间，不得占用其他周期的预留。

### 4.4 仓库与物品

1. 只按体积存储，不规定形状和槽位。
2. 仓库建筑尺寸为 `3×4`，不雇佣居民，默认容量为 `2000`。
3. 大多数可工作建筑可以带默认容量为 `1000` 的自带库存，但该库存是可选能力。
4. 当前物品只有废料、金属、塑料和线。
5. 工作需求锁定具体物品数量；产出在周期开始前预留具体体积。
6. 产出不需要居民前往仓库，由库存系统在周期结算时写入。
7. 所有锁定和容量预留必须具有唯一所有者，并在完成或取消时恰好释放一次。

## 5. 术语

| 术语 | 含义 |
| --- | --- |
| 雇主 | 与居民建立雇佣关系的建筑 |
| 雇员 | 当前属于某个建筑、尚未被解雇或失去资格的居民 |
| 目标人数 | 玩家在建筑详情页设置的期望雇员数量 |
| 最大人数 | 建筑允许设置的目标人数上限 |
| 运行阈值 | 建筑内部可选隐藏阈值，低于它时建筑功能可能不完整 |
| 工作类型 | 定义需求、周期时间、具体行为和产出的规则 |
| 工作周期 | 一次不可被普通需求打断的完整劳动事务 |
| 物品锁定 | 防止已经决定取用的具体物品数量被别人使用 |
| 空间预留 | 为尚未产生的周期产出保留仓库体积 |
| 硬中断 | 解雇、死亡、建筑移除、虚弱等可以打断锁定周期的原因 |
| 自带库存 | 某个建筑私有、随建筑存在的库存 |
| 外部仓库 | 独立仓库建筑提供的库存 |
| 所有者消失清算 | 建筑或居民被删除后，自动转移其物资并销毁剩余部分 |
