# 测试与验收

## 1. 当前验证基线

项目没有自动化测试框架、格式化工具或静态检查工具。验收依赖：

- Godot 无头导入。
- `TestScene` 集成场景。
- 日志中的期望值和实际值。
- 编辑器人工检查 UI、放置和动画。

本版实现后，每次场景或代码改动至少执行：

```powershell
godot --headless --path . --import
git diff --check
godot --headless --path . --log-file .godot/v014_acceptance.log --scene res://Scenes/TestScene.tscn -- --acceptance
```

并运行与雇佣、工作周期、仓库有关的测试场景。

## 2. 雇佣测试

| ID | 场景 | 预期 |
| --- | --- | --- |
| EMP-01 | 不可雇佣建筑 | 不显示人数控件，不扫描居民 |
| EMP-02 | 目标人数超过最大值 | 被夹到 `max_workers` |
| EMP-03 | 目标人数为 0 | 解雇全部多余雇员 |

| EMP-05 | 候选不足 | 补齐可用人数，下一刻继续尝试 |
| EMP-06 | 人数超额 | 随机解雇恰好超额数量 |
| EMP-07 | 两个建筑同时招聘 | 同一居民不会获得两个雇主 |
| EMP-08 | 默认年龄限制 | 儿童和老年人不会被默认雇佣 |
| EMP-09 | 允许特定年龄的建筑 | 符合该建筑规则的人可以被雇佣 |
| EMP-10 | 居民年龄变化后失去资格 | 移除、通知、同刻补招 |
| EMP-11 | 雇佣期间眩晕 | 默认保留雇佣关系 |
| EMP-12 | 建筑删除 | 所有雇员收到结束通知且没有悬空引用 |
| EMP-13 | 目标人数低于隐藏运行阈值 | 允许设置，不自动抬到阈值 |
| EMP-14 | 候选居民多于空缺 | 按稳定注册顺序选择 |
| EMP-15 | 已雇佣但暂时走不到雇主 | 保留雇佣，等待后按决策周期重试 |

## 7. UI 人工检查

- 可雇佣建筑显示目标人数，范围正确。
- 不可雇佣建筑不显示雇佣控件。
- 仓库详情正确显示已用、预留和可用体积。
- 每刻刷新不打断数字输入焦点。
- 目标人数修改后触发补齐或随机解雇。
- 放置仓库时预览、入口、连续放置和取消行为正常。
- 窗口缩放时详情页文本和控件不重叠。

## 8. 日志检查

无头运行不能只看退出码。至少检查：

- 没有 `SCRIPT ERROR`。
- 没有未知状态机事件。
- 没有重复记账或负库存。
- 没有孤立锁定、孤立预留或失效引用。
- 随机解雇后人数恰好等于目标。
- 自动清算结果与环境容量一致。

## 9. 完成定义

- 雇佣目标、补齐和解雇行为通过。
- 默认年龄和班次规则通过。
- 未就业和下班居民去等待点。
- 工作周期依赖和产出空间预留都成功后才开始。
- 周期内普通需求不中断，硬中断能完整回滚。
- 仓库权限、体积、锁定、预留和清算符合本目录规则。
- 建筑和居民删除后没有悬空雇佣、库存或预留引用。
- UI、放置和等待偏移经过人工检查。
