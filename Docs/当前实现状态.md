## 2. 当前核心行为

- `Human.on_tick()` 固定按 Buff、基础水食消耗、AI 推进的顺序执行。
- 可雇佣建筑每刻复检雇员资格，并补齐或随机解雇到目标人数。
- 居民从雇主自带库存或外部仓库锁定工作需求，随后实际前往取货。
- 取出的工作需求进入 `Human.carry`，不再留在全局账本的“虚拟背包”中。
- 工作周期结算核对居民背包实物；取消时按锁来源退回，来源失效时按距离转移。
- 周期成功结算后居民仍保持站内占用并隐藏，真正离站时才恢复世界显示。
- 建筑拆除会先结束雇佣和工作周期，再注销建筑、恢复占格并清算自带库存。
- 建筑支持 `rotation_steps` 四向旋转；旋转 90 度或 270 度时占格宽高互换。
- 放置预览按 `R` 顺时针旋转，落点按新占格重新居中。
- 产出不需要居民实际走向仓库，保存空间在周期开始前预留，结算时直接写入库存。
- `World` 统一挂载正式玩家状态栏，显示六种仓库物资、人口和三段式时间。
- 状态栏摘要由库存、居民、建筑和时间信号驱动；悬停详情只在展开期间刷新。

## 3. 当前场景与默认值

- `ScrapSortingStation` 类默认 `target_workers = 0`。
- `Scenes/TestScene.tscn` 的初始化代码显式把废料分拣站目标人数设为 `3`，
  因此常规集成场景会自动招聘并覆盖工作周期。
- 调试放置的居民统一为成年人，年龄范围为 `18..59`。
- 默认班次是每个游戏日的 `600..1499` 刻。

## 4. 当前 UI 事实

顶部玩家状态栏当前提供：

- 水、食物、废料、塑料、金属、线的白色图标、数量和竖线分隔。
- 水/食物存在无限材料站时显示“无限”。
- 儿童、成人和老人数量。
- `dddd天tttt刻` 格式的游戏时间，第一天从 `0001天0000刻` 开始。
- 每个信息项的悬停详情，使用统一板块、标题和文本行面板。
- 状态栏矩形控件拦截鼠标，宽度按信息项动态变化并保持顶部居中。
- 倒置梯形外观当前使用深色底板、细微阴影和灰白描边。

建筑详情页当前提供：

- 可雇佣建筑的目标人数数字输入。
- 当前雇员数量和可补位候选人数。
- 当前班次状态。
- 自带库存的容量、已用体积、已预留体积和可用体积。
- 非零物品的数量和锁定数量。
- 拆除按钮。

当前没有背包查看界面、背包容量或负重规则。
