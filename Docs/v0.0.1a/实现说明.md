# v0.0.1a 实现说明

## 时间换算

| 项目 | 数值 |
| --- | --- |
| 现实时间 | 1 秒 = 6 刻（`TickManager.TICKS_PER_SECOND`），一天 = 现实 300 秒（5 分钟） |
| 游戏内一天 | 1800 刻 = 6 小时 |
| 游戏内一刻 | 12 秒 |
| 一格 | 1 米（`WorldGrid.CELL_SIZE` = 10 像素） |

所以人的移动速度要乘游戏内秒数：成年人 1.4 米/秒 × 12 = **16.8 格/刻**。
一天走三十公里，一屏 28 格要走将近两刻，画面上看得出人在动。

## 每刻做什么

`TickManager.advance_tick()` 每刻按固定顺序更新：

1. 所有建筑 `on_tick()`
2. 所有居民 `on_tick()`（扣水扣食物 → 每 5 刻决策 → 移动 / 等待）
3. 广播 `tick_advanced`、跨天时广播 `day_advanced`

新东西要更新，用 `TickManager.register_building()` / `register_human()` 登记，别自己连 `_process`。

## 居民决策

每 5 刻比较三个权重，取最大的：

```
水权重   = 1800 ÷ 水还能撑几刻
食物权重 = 1800 ÷ 食物还能撑几刻
工作权重 = 10（固定）
```

1800 = `URGENT_GAME_SECONDS`(2160 游戏秒 = 36 分钟) ÷ 每刻 12 秒 × `WORK_WEIGHT`(10)，
意思是**还剩 36 分钟的量时，权重刚好追平工作**，人就出门补给。
用「还剩几刻」而不是「还剩多少毫升」，是为了让儿童和成人各自按自己的消耗速度动身，不会因为总量相同就一起跑。
提前量用的是游戏内秒数，改 `TICKS_PER_DAY` 之后会自动换算，不用跟着改。

- 已经在去水 / 去食物的路上（移动或等待中）时，不换目标
- 每人的决策时刻随机错开，避免全城同一刻一起涌向水站
- 补满后立刻重新决策，不用干等 5 刻

## 各年龄段的日耗和速度

| 年龄段 | 每日水（ml） | 每日食物（g） | 步行速度（米/秒） |
| --- | --- | --- | --- |
| 儿童 | 500 | 800 | 1.0 |
| 成年 | 1700 | 1900 | 1.4 |
| 老年 | 1500 | 1500 | 1.2 |

- 老人文档里没写，代码暂时按「无业成年人」处理（水 1500、食物 1500），速度也自己定成 1.2，要改就改 `Human.get_daily_water/food()` 和 `get_speed_cells_per_tick()`
- 年轻人按「有业成年人」算（1700 / 1900），因为都要上班
- 身上的水和食物上限都是 700，日耗是按「游戏日」算的，所以一天要补两三次

## 建筑

- 矩形，`size_cells` 个格，左上角落在格线上（`origin_cell` 是格子坐标，天然对齐）
- `entrance_offsets` 是相对左上角的偏移，可以有任意多个
- 放置校验：本体每格必须是空地；出入口必须在矩形外、和矩形边相邻（只碰角不算）、本身是空地
- 出入口可以和别的建筑的出入口重叠
- 放好后本体占的格子设为不可走

| 建筑 | 尺寸 | 出入口 | 停留 |
| --- | --- | --- | --- |
| 取水站 | 4×3 | 1 个 | 2 刻 |
| 取食站 | 4×3 | 2 个 | 2 刻 |
| 工作站 | 6×4 | 2 个 | 1 刻后进入内部 |

工作站里模型隐藏，水和食物照常消耗，直到触发补给才出来。

## 白模与调试放置

所有图形都是代码画的，没有贴图：

- 建筑：白色主体 + 顶部深色檐口 + 类型符号（取水站水滴、取食站碗、工作站齿轮）+ 黄色出入口
- 进入工作站的居民模型隐藏，不画在建筑里；左上角统计单独列一行「站内 N」就是他们
- 居民：头 + 身体 + 四肢，衣服颜色表示当前状态（蓝=去取水、橙=去取食、紫=上班、绿=空闲、灰=虚弱）
- 出生一人一格、手动放人也拒绝同一格，所以「空闲 / 取水 / 取食 / 上班路上」这几个数字加起来就是画面上能看到的人数

统计口径：

```
取水 / 取食     正在去补给或站在补给站门口
上班路上        正在走去工作站
站内            已经进门，模型隐藏
空闲            还没轮到第一次决策，或找不到对应建筑，或虚弱到不再行动
```

放置规则：

- 建筑只检查「格子是不是空地」，**不检查有没有人站着**
- 如果建筑压到了人，被压住的人会自己走到最近的一块空地上（四周被包住没有路时直接挪出去），然后继续原来的行为

调试面板（左上角）可以直接往地图上放东西：

- 点「取水站 / 取食站 / 工作站 / 居民」，鼠标位置出现半透明预览，**建筑以鼠标所指的那一格为中心对齐**
- 预览描边绿色 = 这一格能放，红色 = 不能放
- 绿色时左键放下；放下后模式不变，可以接着点下一处连续放
- 右键或 ESC 取消
- 居民只能放在可走的空地上，年龄随机（儿童 / 成年 / 老年各三分之一）

自动化验证（不开窗也能跑）：

```
godot --headless -- --autoplace --max-ticks=30
```

会放一个取水站、一个居民，再故意重叠放一次，输出 `水站=true 居民=true 重叠(应 false)=false 压建筑(应 false)=false`。

## 调参位置

| 想改什么 | 改哪里 |
| --- | --- |
| 一天多少刻 / 现实一秒几刻 / 一天几游戏小时 | `Scripts/Core/TickManager.gd` 顶部三个常量 |
| 什么时候出门补给（提前量） | `Human.URGENT_GAME_SECONDS`（2160 游戏秒 = 36 分钟） |
| 工作权重 | `Human.WORK_WEIGHT`（10） |
| 决策间隔 | `Human.DECISION_INTERVAL`（5 刻 = 游戏内 1 分钟） |
| 各年龄段日耗 / 速度 | `Human.get_daily_water/food()`、`get_speed_cells_per_tick()` |
| 世界大小 / 格子像素 | `WorldGridGlobal.WORLD_CELLS`、`WorldGrid.CELL_SIZE` |
| 建筑尺寸 / 出入口 | 各建筑脚本的 `_init()`（`size_cells`、`entrance_offsets`） |

> 改 `TICKS_PER_DAY` 只需要改这一个常量：每日消耗、移动速度、补给提前量都是按它算出来的。
> 改 `TICKS_PER_SECOND` 只影响「现实里看多久」，游戏内数值一个都不变。

## 调试

运行后：

- 空格：暂停 / 继续
- 数字 1~4：1 / 2 / 5 / 20 倍速
- 左上角显示天、刻、各状态人数

命令行（在项目目录）：

```
godot -- --speed=600 --max-ticks=5400
```

快进跑 5400 刻（3 个游戏日），每 100 刻打印一次每个人的水和食物，跑完自动退出。
加 `--shot=路径.png` 可以在第 60 刻截一张图。

## 当前限制（v0.0.1a 没做的）

- 建筑是测试场景里用代码摆的，还没有「玩家放置 / 建造」的交互
- 虚弱只是停下来，没有死亡、医院、治疗
- 工作站进去后没有产出，只是个「待着的地方」
- 三个人挤同一个出入口不会排队，只是叠在一起
- 没有存档
